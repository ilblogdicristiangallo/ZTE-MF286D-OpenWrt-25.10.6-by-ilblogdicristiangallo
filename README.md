# ZTE-MF286D-OpenWrt-24.10.6-by-ilblogdicristiangallo
Custom OpenWrt 25.12.6 firmware and APK repository for ZTE MF286D, built on Linux (ipq40xx). Includes LuCI, QMI/MBIM modem support, ModemManager, WireGuard, modem tools, HTTPS-enabled package management, plus custom packages apn-web and telegramWrt, ready to use after sysupgrade.
